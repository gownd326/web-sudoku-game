# 웹 스도쿠 퍼즐 (Web Sudoku Game)

누구나 별도의 회원가입 없이 브라우저에서 가볍게 즐길 수 있는 반응형 웹 스도쿠 게임입니다.

## 주요 기능
- 난이도별(초급, 중급, 고급) 무작위 9x9 퍼즐 생성
- 키보드 입력 및 화면 내 터치/클릭 숫자 패드 지원
- 빈칸에 후보 숫자를 작게 적어둘 수 있는 메모(Pencil Marks) 모드
- 타이머 및 일시정지(Pause) 기능
- 스도쿠 규칙에 어긋나는 숫자를 실시간으로 감지하는 오답 검증(빨간색 표시)
- 정답 중 1개를 오픈하는 힌트 기능
- 최고 기록 로컬스토리지 저장 및 축하 모달

## 프로젝트 실행 방법 (비전문가용)

이 프로젝트를 로컬 컴퓨터에서 실행하려면 Node.js(버전 20 이상 권장)가 설치되어 있어야 합니다.

1. **저장소 다운로드 및 압축 해제**
   프로젝트 소스 코드가 포함된 폴더를 원하는 경로에 준비합니다.

2. **터미널(명령 프롬프트) 열기**
   프로젝트 루트 폴더(`web-sudoku-game`) 경로로 이동합니다.

3. **필수 패키지 설치**
   아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.
   ```bash
   npm install
   ```

4. **개발 서버 실행**
   설일 완료 후 아래 명령어를 입력합니다.
   ```bash
   npm run dev
   ```

5. **웹 브라우저에서 접속**
   터미널에 표시되는 로컬 주소(예: `http://localhost:5173`)를 복사하여 브라우저 주소창에 입력하면 게임을 시작할 수 있습니다.

## 테스트 실행 방법
작성된 유닛 및 통합 테스트를 실행하려면 아래 명령어를 입력하세요.
```bash
npm test
```
