## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 목적
- 누구나 별도의 회원가입 없이 브라우저에서 가볍게 즐길 수 있는 반응형 웹 스도쿠 게임 제공

### 핵심 가치
- 직관적인 UI와 빠른 로딩 속도
- 난이도별(초급, 중급, 고급) 퍼즐 제공
- 오답 체크 및 힌트 기능으로 사용자 편의성 극대화

## 2. 사용자와 사용 시나리오

### 주요 사용자
- 두뇌 운동과 퍼즐 게임을 좋아하는 일반 웹 사용자

### 사용 시나리오
- **시나리오 1: 게임 시작**
  - Given: 사용자가 메인 페이지(`/`)에 접속한다.
  - When: 원하는 난이도(초급/중급/고급)를 선택하고 '게임 시작' 버튼을 누른다.
  - Then: 9x9 스도쿠판이 생성되고 타이머가 작동하기 시작한다.
- **시나리오 2: 숫자 입력 및 오답 확인**
  - Given: 게임판의 빈칸을 클릭했다.
  - When: 화면 하단의 숫자 패드(1~9)를 눌러 숫자를 채운다.
  - Then: 즉시 칸에 숫자가 입력되며, 설정에 따라 틀린 숫자가 빨간색으로 표시된다.

## 3. 기능 명세

### 핵심 기능 목록
- **스도쿠 보드 생성**: 난이도(초급, 중급, 고급)에 따른 무작위 9x9 퍼즐 생성 알고리즘 탑재
- **숫자 입력 인터페이스**: 키보드 입력 및 화면 내 터치/클릭 숫자 패드 지원
- **메모(Pencil Marks) 기능**: 빈칸에 후보 숫자를 작게 여러 개 적어둘 수 있는 모드 제공
- **일시정지(Pause) 기능**: 타이머를 멈추고 화면을 가려 퍼즐을 숨기는 일시정지 버튼 제공
- **오답 실시간 검증**: 스도쿠 규칙에 어긋나는 숫자를 입력 시 즉시 빨간색으로 표시
- **타이머 및 기록**: 게임 진행 시간 측정, 최고 기록 로컬 저장(LocalStorage)
- **편의 기능**: 힌트 보기(정답 중 1개 오픈), 지우기, 새 게임 시작

## 4. 화면과 주소(URL) 구성

### 화면 목록
1. **메인/게임 화면 (`/`)**
   - 경로: `/`
   - 주요 구성 요소:
     - 상단: 게임 제목, 난이도 표시, 타이머, 최고 기록, '일시정지' 버튼
     - 중앙: 9x9 스도쿠 그리드 (3x3 박스 강조선, 일시정지 시 '게임 일시정지됨' 오버레이 표시)
     - 하단: 메모 모드 토글 버튼, 숫자 패드(1~9), 지우기, 힌트, 새 게임 버튼
   - 색상 테마: 배경 `#F8FAFC`, 보드 테두리 `#0F172A`, 강조색 `#3B82F6`

## 5. 데이터 모델

### 데이터 저장 방식
- 서버 데이터베이스 없이 브라우저의 `LocalStorage`를 활용합니다.
- 저장 항목:
  - `sudoku_best_time_{difficulty}` (숫자): 난이도별 최고 클리어 타임(초 단위)
  - `sudoku_saved_game` (JSON 문자열): 진행 중이던 게임 상태 임시 저장

## 10. 테스트 계획

### 수용 기준 (Given / When / Then)
- **시나리오 1: 게임 시작 및 난이도 선택**
  - Given: 사용자가 메인 페이지(`/`)에 접속한다.
  - When: 난이도(초급/중급/고급)를 선택하고 '새 게임' 버튼을 클릭한다.
  - Then: 해당 난이도의 빈칸이 포함된 9x9 보드가 생성되며 타이머가 00:00부터 시작한다.
- **시나리오 2: 숫자 입력 및 실시간 오답 검증**
  - Given: 게임판의 빈칸을 선택했다.
  - When: 숫자 패드에서 `5`를 입력한다.
  - Then: 선택한 칸에 `5`가 채워지며, 스도쿠 규칙(가로/세로/3x3 박스 내 중복)에 위배될 경우 글자 색상이 빨간색(`text-red-500`)으로 표시된다.
- **시나리오 3: 일시정지 기능**
  - Given: 게임이 진행 중이다.
  - When: 상단의 '일시정지' 버튼을 누른다.
  - Then: 타이머가 멈추고, 스도쿠 보드 영역이 '일시정지됨' 오버레이로 가려진다.
- **시나리오 4: 게임 클리어**
  - Given: 스도쿠 보드의 모든 칸을 규칙에 맞게 올바르게 채웠다.
  - When: 마지막 숫자가 입력되는 순간
  - Then: 타이머가 멈추고 축하 모달이 나타나며 소요된 시간이 최고 기록과 비교되어 로컬스토리지에 갱신된다.
