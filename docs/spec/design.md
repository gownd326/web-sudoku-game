## 1. 화면과 주소(URL) 구성

### 화면 목록
1. **메인/게임 화면 (`/`)**
   - 경로: `/`
   - 주요 구성 요소:
     - 상단: 게임 제목, 난이도 표시, 타이머, 최고 기록, '일시정지' 버튼
     - 중앙: 9x9 스도쿠 그리드 (3x3 박스 강조선, 일시정지 시 '게임 일시정지됨' 오버레이 표시)
     - 하단: 메모 모드 토글 버튼, 숫자 패드(1~9), 지우기, 힌트, 새 게임 버튼
   - 색상 테마: 배경 `#F8FAFC`, 보드 테두리 `#0F172A`, 강조색 `#3B82F6`

## 2. 디자인 가이드

### 디자인 가이드
- **색상 팔레트 (Tailwind CSS 기준)**
  - 배경: `bg-slate-50` (`#F8FAFC`)
  - 카드/보드 배경: `bg-white` (`#FFFFFF`)
  - 주요 텍스트: `text-slate-900` (`#0F172A`)
  - 주조색(Primary): `bg-blue-600` (`#2563EB`) - 버튼 및 활성 요소
  - 강조/오답: `text-red-500` (`#EF4444`)
- **폰트**: 기본 시스템 산세리프 폰트 적용
