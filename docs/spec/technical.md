## 1. 데이터 모델

### 데이터 저장 방식
- 서버 데이터베이스 없이 브라우저의 `LocalStorage`를 활용합니다.
- 저장 항목:
  - `sudoku_best_time_{difficulty}` (숫자): 난이도별 최고 클리어 타임(초 단위)
  - `sudoku_saved_game` (JSON 문자열): 진행 중이던 게임 상태 임시 저장

## 2. 기술 스택과 폴더 구조

### 기술 스택
- **프레임워크**: Vite + React + TypeScript
- **스타일링**: Tailwind CSS
- **아이콘**: Lucide React
- **배포**: Vercel

### 폴더 및 파일 구조
```text
src/
├── components/
│   ├── SudokuBoard.tsx   # 9x9 스도쿠 그리드 및 셀 컴포넌트
│   ├── NumberPad.tsx     # 숫자 패드 및 메모 모드 토글
│   ├── ControlPanel.tsx  # 난이도 선택, 타이머, 힌트, 새 게임, 일시정지 버튼
│   └── WinModal.tsx      # 게임 클리어 축하 및 기록 표시 모달
├── utils/
│   ├── sudokuGen.ts      # 스도쿠 퍼즐 생성 및 검증 알고리즘
│   └── storage.ts        # LocalStorage 연동 유틸 (최고 기록 및 진행 상태 저장)
├── App.tsx               # 메인 페이지 및 상태 관리(타이머, 보드 상태, 일시정지)
├── main.tsx              # 앱 진입점
└── index.css             # Tailwind CSS 설정 및 글로벌 스타일
```

### 환경 변수
- 백엔드가 없으므로 별도의 환경 변수는 필요하지 않습니다.

## 3. 품질 기준 (성능·보안·접근성)

### 품질 기준
- **성능**: 첫 페이지 로딩 속도 1초 이내 (Lighthouse 성능 95점 이상)
- **반응형**: 모바일 화면(375px 이상)부터 데스크톱 화면까지 깨짐 없이 작동
- **접근성**: 버튼 및 입력 칸에 적절한 ARIA 레이블 제공
